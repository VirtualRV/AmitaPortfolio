# Amita Dubey — Creative Portfolio

> **Graphic Designer | UI Designer | Motion Designer**  
> High-impact portfolio replica built with the editorial design aesthetics of Okta Studio Framer.

---

## ✦ Highlights

- **Aesthetic**: Modern dark editorial design system (`#0d1110`), International Orange accents (`#ff4d1c`), bone white typography (`#f2efe9`), with `Hanken Grotesk` and `Inter`.
- **Live IST Clock**: Live digital clock with seconds in Asia/Kolkata timezone with a pulsing status dot.
- **Dual Marquee Tickers**: Smooth infinite rolling ticker banners moving in opposite directions.
- **Interactive Projects & Sticky Preview**: Dynamic preview changes on hover, complete with an interactive **Case Study Modal** and a filterable **Full Archive Modal**.
- **Software Disciplines**: Photoshop, Illustrator, After Effects, Figma, Canva, Premiere Pro & Lightroom.
- **Process & Career Timeline**: Documenting 5+ years of experience across Zenesys Technosys Pvt. Ltd. and Magic Software / Tekshapers.
- **Interactive Brief Form**: Custom service and budget pill selectors with instant verification.

## 🚀 Running Locally

Clone the repository and start the server:

```bash
git clone https://github.com/VirtualRV/AmitaPortfolio.git
cd AmitaPortfolio
node local-server.js
```

Then visit:
```
http://localhost:3000/
```
